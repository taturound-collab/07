NomGI — พื้นที่แบ่งปันน้ำใจ ที่รับฟังกันแบบนิรนาม

เว็บแอปแชท peer-support ภาษาไทย ที่จับคู่ “คนอยากระบาย” กับ “คนพร้อมรับฟัง” แบบไม่เปิดเผยตัวตน พร้อมเครื่องมือดูแลใจ ระบบความปลอดภัย และชุมชนให้กำลังใจ — ออกแบบให้รู้สึกอบอุ่น นุ่มนวล ปลอดภัย ตั้งแต่วินาทีที่เปิดหน้าเว็บ

React 18 ผ่าน CDN + Babel ไม่มี build step Supabase · Postgres + RLS Tailwind CDN PWA ติดตั้งได้ Deploy บน Vercel 12 หน้า · 20+ ตาราง

01 · ภาพรวม

NomGI เกิดมาเพื่อเป็น “ห้องนั่งเล่นที่มีคนพร้อมฟังเสมอ” — ไม่ใช่แอปเทคโนโลยีเย็นชา และไม่ใช่คลินิกที่เป็นทางการ

หัวใจของแอป

ผู้ใช้เลือกบทบาทได้ 2 อย่าง แล้วระบบจับคู่ให้อัตโนมัติเป็นห้องแชทส่วนตัว 1:1 หรือจะเข้าห้องกลุ่มเล็กก็ได้

ฉันอยากระบาย ⇄ ฉันอยากรับฟัง → เข้าคิว → จับคู่ → ห้องแชทนิรนาม → พิธีกรรมปิดจบอย่างอบอุ่น
🕊️

ใครใช้

วัยรุ่น นักเรียน นักศึกษาไทย ที่อยากระบายแบบไม่เปิดเผยตัว และอาสาสมัคร “ผู้รับฟัง” ที่อยากช่วยเพื่อน

🌙

ใช้ตอนไหน

บนมือถือเป็นหลัก มักใช้ตอนกลางคืน ในช่วงที่ใจไม่ดี — จึงต้องรู้สึกปลอดภัยทันที

🎯

ความสำเร็จ

ผู้ใช้รู้สึกเบาใจขึ้นหลังใช้ และกลับมาใช้ซ้ำเพราะไว้ใจพื้นที่นี้

หลักการออกแบบ 5 ข้อ

สงบก่อนสวย

ทุกหน้าต้องลดความเครียดของคนที่กำลังใจไม่ดี ไม่เพิ่ม

ค่อยๆ เผย ไม่เทกอง

ฟีเจอร์เยอะได้ แต่หน้าจอเดียวต้องมีลำดับชัด สิ่งรองพับเก็บได้

ความเป็นส่วนตัวมองเห็นได้

จุดไหนข้อมูลอยู่แค่ในเครื่อง/นิรนาม บอกซ้ำๆ ด้วยภาษาอ่อนโยน

มือถือคือหน้าจอจริง

เริ่มออกแบบที่จอแคบ ปุ่มใหญ่พอสำหรับนิ้ว

ความปลอดภัยถึงก่อนเสมอ

ปุ่มหนีด่วน สายด่วน และทางออก ต้องหาเจอได้ในทุกสภาวะโดยไม่รก

02 · สถาปัตยกรรม & เทคโนโลยี

จุดเด่นคือ “ไม่มีขั้นตอน build” — ทุกหน้าเป็นไฟล์ .html เดี่ยวๆ ที่คอมไพล์ JSX ในเบราว์เซอร์ ทำให้แก้และ deploy ได้ทันที

⚛️

Frontend

React 18 โหลดผ่าน CDN + Babel Standalone แปลง JSX ในเบราว์เซอร์ · จัดสไตล์ด้วย Tailwind CDN ที่ผูกสีกับ CSS variables (var(--color-*))

🗄️

Backend

Supabase — Postgres, Row Level Security (RLS), Realtime, Auth และฟังก์ชัน SECURITY DEFINER · config.js เก็บแค่ anon key ที่เปิดเผยได้ (ความปลอดภัยจริงอยู่ที่ RLS)

🎨

ธีม & การเข้าถึง

theme.js คุมโหมดสว่าง/มืด ปรับขนาดฟอนต์ (0.9–1.3×) และลดการเคลื่อนไหว — ทุกหน้าโหลดไฟล์นี้

📲

PWA

manifest.webmanifest + service-worker.js (แคชเฉพาะไฟล์สแตติก ไม่แคช HTML) ติดตั้งลงจอโฮมได้

การนำขึ้นระบบ (Deploy)

แก้ไฟล์ในเครื่อง → git commit → sync ไปโฟลเดอร์ blissiam-chat3/ บน branch หลัก → push origin main → Vercel auto-build ขึ้นเว็บจริง
🔒

ความเป็นส่วนตัวโดยการออกแบบ: ข้อมูลส่วนตัว (บันทึกอารมณ์ · สมุดขอบคุณ · แผนรับมือ · เส้นทางดูแลใจ) เก็บใน localStorage เท่านั้น ไม่ขึ้นเซิร์ฟเวอร์ — key ขึ้นต้นด้วย nomgi_ ทั้งหมด ผู้ใช้ส่งออกเป็นไฟล์ หรือลบทิ้งได้เอง

04 · เส้นทางการพัฒนา

ทุกฟีเจอร์ปล่อยเป็นชุด (batch) ทีละนิด เพื่อคุมคุณภาพและไม่พังของเดิม — นี่คือลำดับจริงตั้งแต่ต้น

Phase 1–3

รากฐาน: จับคู่ ระบาย รับฟัง

  • แชท 1:1 นิรนาม + คิวจับคู่อัตโนมัติ + เลือกเปิด/ปิดตัวตน
  • เช็คอินอารมณ์ก่อนคุย · ต้นไม้น้ำใจที่โตตามการให้กำลังใจ · พิธีกรรมปิดจบอย่างอบอุ่น
  • เลือกแบบที่อยากให้ช่วย (แค่ฟัง / อยากได้คำแนะนำ / อยากมีเพื่อน)
  • วงกลมแบ่งปัน — ห้องกลุ่มเล็กตามหัวข้อ
Batch A

ความปลอดภัย + ความอบอุ่นเริ่มต้น

  • ตรวจจับภาวะวิกฤต — เจอคำเสี่ยงแล้วเสนอการ์ดสายด่วนอย่างนุ่มนวล
  • การ์ดข้อตกลงก่อนคุย · ประโยคเปิดบทสนทนา + การ์ดกำลังใจสำเร็จรูป · บันทึกสะท้อนใจหลังคุย
Batch B

นิสัยและการสะสม

  • สถิติเช็คอินรายวัน (streak) · เหรียญตราสะสมตามน้ำใจ · ทำเป็น PWA ติดตั้งได้
Batch C

ควบคุมคุณภาพ (ต้องใช้ SQL)

  • บล็อก/ข้ามคู่สนทนา · ให้คะแนนหลังคุย · ล็อกกันจับคู่กับตัวเอง · อารมณ์รวมของชุมชนแบบนิรนาม (ดูในหลังบ้าน)
5 ฟีเจอร์เขียว

ดูแลใจ + การเข้าถึง

  • ฝึกหายใจ 4-7-8 · สรุปรายสัปดาห์ · ปรับขนาดฟอนต์ + ลดการเคลื่อนไหว · ทัวร์ครั้งแรก · สมุดขอบคุณรายวัน
Batch D

สื่อสารและปฏิสัมพันธ์

  • React ข้อความด้วยอีโมจิ (เรียลไทม์) · แท็กความถนัดของผู้รับฟัง · วงกลมมีเวลานัด (คืนวันอาทิตย์) · ระบบอุทธรณ์การแบน
Batch E

ปลอดภัย + เป็นส่วนตัว (frontend ล้วน)

  • ปุ่มออกด่วน (แถบริมจอ + Esc×2) · ดึงสติ 5-4-3-2-1 · แผนรับมือของฉัน · ส่งออก/ลบข้อมูลส่วนตัว
Batch F

ความต่อเนื่องและชุมชน (ต้องใช้ SQL)

  • กลับมาคุยกับคนเดิม (ยินยอมทั้งสองฝ่าย) · กำแพงให้กำลังใจ · เหรียญ ผู้ฟังที่ไว้ใจได้ · กันผู้ฟังหมดไฟ · Auto-flag คำเสี่ยงเข้าคิว admin
UI Pass

ปรับให้สงบและกระชับ

  • หน้าแรกใช้ชิปกะทัดรัด · แชทแตะง่ายบนมือถือ · โปรไฟล์จัดหมวดพับได้
Batch G

ยกระดับคุณภาพผู้รับฟัง (ต้องใช้ SQL)

  • คอร์สปั้นผู้รับฟัง (4 บทเรียน + แบบทดสอบ) → เหรียญ ผ่านการอบรม
  • ส่งต่ออย่างอบอุ่น — พาคู่สนทนาไปหาความช่วยเหลือที่เหมาะสม · แท็บวิเคราะห์เชิงลึกในหลังบ้าน
Batch H

ดูแลใจให้ลึกและต่อเนื่อง (frontend ล้วน)

  • มุมดูแลใจ — เส้นทาง 7 วัน · เครื่องมือคลายใจ · แหล่งช่วยเหลือ · เช็คอินตามหลังเมื่อเมื่อวานใจหนัก

05 · ฐานข้อมูล

ทุกตารางเปิด Row Level Security — ผู้ใช้เห็น/แก้ได้เฉพาะข้อมูลของตัวเองหรือห้องที่ตัวเองอยู่ · งานที่ละเอียดอ่อนทำผ่านฟังก์ชัน SECURITY DEFINER

ตารางเก็บอะไร
profilesผู้ใช้ · ชื่อแสดง · น้ำใจ · สถานะ · ความถนัด · คะแนนเฉลี่ย · ผ่านการอบรม
rooms · messagesห้องแชท 1:1 และข้อความ (เรียลไทม์)
queueคิวรอจับคู่ + trigger match_users() จับคู่อัตโนมัติ
group_rooms · group_membersห้องกลุ่มและสมาชิก + ฟังก์ชัน join_group()
room_kudos · ratingsการให้น้ำใจ และคะแนนหลังคุย
message_reactionsอีโมจิที่แตะบนข้อความ
reports · blocksรายงานปัญหา และการบล็อก
mood_pingsอารมณ์รวมชุมชน — ไม่มี user_id (นิรนามจริง)
ban_appealsคำอุทธรณ์ของผู้ถูกแบน
saved_partners · reconnect_invitesบันทึกคู่คุย และคำเชิญกลับมาคุย
wall_posts · wall_heartsกำแพงกำลังใจและหัวใจ
safety_flagsสัญญาณเสี่ยงที่ auto-flag เข้าคิวผู้ดูแล
site_settingsธีมเว็บที่ผู้ดูแลตั้ง
🧩

ฟังก์ชันฝั่งเซิร์ฟเวอร์: match_users() จับคู่ตามหัวข้อ/แบบที่อยากให้ช่วย · give_kudos() · join_group() · my_reconnectable(), request_reconnect(), accept_reconnect() · get_partner_identity() เผยตัวตนเฉพาะเมื่อทั้งคู่ยินยอม — ทั้งหมดเป็น SECURITY DEFINER ที่ตรวจสิทธิ์เองอย่างรัดกุม

ฟีเจอร์ที่ต้องใช้ SQL จะมาเป็นไฟล์ supabase-batch-*.sql ให้เจ้าของรันเองใน Supabase SQL Editor (รันซ้ำได้ปลอดภัย — ใช้ IF NOT EXISTS / DROP POLICY IF EXISTS ครอบไว้)

06 · ความปลอดภัย & ความเป็นส่วนตัว

เพราะผู้ใช้กำลังเปราะบาง เรื่องนี้จึงมาก่อนทุกอย่าง — ออกแบบเป็นหลายชั้นซ้อนกัน

🆘

ตรวจจับภาวะวิกฤต

ทำงานฝั่งเบราว์เซอร์ล้วน (safety.js) เจอสัญญาณเสี่ยงแล้วเสนอสายด่วน 1323 / สะมาริตันส์ / 1669 อย่างนุ่มนวล ไม่บล็อกการคุย

🚪

ปุ่มออกด่วน

แถบเล็กริมจอทุกหน้า + กด Esc สองครั้ง = เด้งไปหน้ากลางๆ ทันที ใช้ location.replace ไม่ทิ้งประวัติ

🎓

ปั้นผู้รับฟังก่อนรับงาน

คอร์สสั้น + แบบทดสอบ ก่อนรับฟังครั้งแรก → เหรียญ “ผ่านการอบรม” เพิ่มคุณภาพและความปลอดภัย

🤍

ส่งต่ออย่างอบอุ่น

ผู้รับฟังกดพาคู่สนทนาไปหาความช่วยเหลือที่เหมาะสมได้ พร้อมสคริปต์ที่ไม่ทำให้รู้สึกถูกทิ้ง

🚩

Auto-flag + Moderation

คำเสี่ยงถูกส่งเข้าคิวผู้ดูแลอัตโนมัติ · มีระบบรายงาน บล็อก แบน และอุทธรณ์ครบวงจร
