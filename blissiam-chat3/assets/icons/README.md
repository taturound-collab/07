# สติกเกอร์ไอคอน Flaticon — วางไฟล์ที่นี่

โฟลเดอร์นี้เก็บไฟล์ไอคอน/สติกเกอร์มีสีที่โหลดมาจาก Flaticon

## วิธีเพิ่มไอคอน
1. เข้า https://www.flaticon.com/ หา icon ที่ต้องการ (เลือก **สไตล์เดียวกัน** ทั้งชุดจะได้กลมกลืน)
2. กด Download → เลือก **SVG** (คมชัดทุกขนาด) แล้วเซฟไฟล์มาไว้ในโฟลเดอร์นี้
   - ตั้งชื่อไฟล์สั้นๆ เช่น `mood-happy.svg`, `tree.svg`
3. เปิด `../../flaticons.js` แล้วเพิ่ม 1 บรรทัดในทะเบียน `STICKERS`:
   ```js
   'mood-5': { file: 'mood-happy.svg', author: 'Freepik', url: 'https://www.flaticon.com/free-icon/...' },
   ```
   - `author` และ `url` = ชื่อผู้วาด + ลิงก์ icon (ดูได้จากหน้า Flaticon ของ icon นั้น)
   - หน้า `credits.html` จะสร้างเครดิตให้อัตโนมัติ

## ⚠️ ลิขสิทธิ์
ไอคอนฟรีของ Flaticon **ต้องให้เครดิต** — ระบบใส่ให้อัตโนมัติผ่านทะเบียนแล้ว
อย่าลบลิงก์ "เครดิต & แหล่งที่มา" ใน footer ออก
